# Suspicion de fuite ou d'exfiltration de données
Procédure générale de laboratoire ; aucune capacité automatique de confinement confirmée.
Accès : responsable de l'incident et opérateurs habilités.
1. Consigner l'heure, le service, les accès inhabituels et les éléments disponibles, sans copier les données sensibles dans le chat.
2. Préserver les journaux utiles et alerter le responsable. Une hausse de trafic seule ne prouve pas une exfiltration.
3. Faire décider par le responsable des restrictions d'accès ou de l'isolement ; ne pas supprimer de fichiers ni de journaux pour faire disparaître le symptôme.
L'assistant fournit la procédure, sans accéder aux données ni isoler les services. La clôture nécessite de vérifier la cause, les accès concernés et le rétablissement du service ; elle ne permet pas d'affirmer que des données copiées ont été récupérées.
